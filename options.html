ASP Legacy Compatibility

ตั้งค่าการทำงานของ Extension สำหรับเว็บ Classic ASP

การทำงานทั่วไป

ปิดถ้าต้องการหยุดทำงานชั่วคราว
ทำงานเฉพาะหน้า URL ลงท้าย .asp/.aspx
แสดง log ละเอียดใน DevTools Console

โดเมนที่ปิดใช้งาน

รายชื่อโดเมน (หนึ่งบรรทัดต่อหนึ่งโดเมน) ที่ไม่ให้ extension ทำงาน

บังคับเปิดสำหรับโดเมน

โดเมนที่ให้ extension ทำงานเสมอ แม้ URL จะไม่ลงท้าย .asp (เช่นเว็บที่ใช้ URL rewriting)
💡 ใส่โดเมนของระบบเก่าที่ใช้ URL rewriting (เช่น /Default.aspx ที่ map เป็น / )

Encoding

⚠️ Extension ไม่สามารถ re-decode หน้าได้หลัง browser parse เสร็จ ถ้าตัวอักษรเพี้ยน ต้องแก้ที่ server (เพิ่ม Response.Charset = "windows-874" หรือ <meta charset="windows-874">)
